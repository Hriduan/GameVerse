Player support

Let’s get you back in game.

Quick answers for a smooth GameVerse session.

Which browsers work best?

Use a recent version of Chrome, Edge, Firefox or Safari with JavaScript enabled.

Do I need to install anything?

No. Every game runs directly in your browser.

How do mobile controls work?

Tap or swipe inside the game area. Each game shows its control hint before the round.

Why is a game running slowly?

Close unused tabs, disable battery saver during play and reload the page.
