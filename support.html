Common questions

Fast answers

Which browsers work best?

Use a current version of Chrome, Edge, Firefox or Safari with JavaScript enabled.

Do I need to install anything?

No. Every game runs directly in your browser and GitHub Pages can host the full static experience.

How do mobile controls work?

Tap, swipe or use the on-screen controls inside the game arena. The exact controls appear under each game.

Why did my game resize?

GameVerse automatically recalculates the arena after rotation or window resizing so controls and graphics remain sharp.

Where are my best scores stored?

Personal bests are stored locally in your browser. Clearing browser storage will reset them.
